# Hi, I'm Fengqianyun

I focus on digital IC design and FPGA development, with an emphasis on RTL design, hardware architecture, and hardware acceleration.

My current projects include FPGA-based real-time image processing systems and KWT-1 feed-forward linear accelerators. I work on hardware architecture, RTL implementation, simulation, synthesis, and performance optimization.

我主要从事数字集成电路设计与 FPGA 开发，关注 RTL 设计、硬件架构与硬件加速。目前主要开展 FPGA 实时图像处理系统和 KWT-1 前馈线性加速器相关项目，注重硬件架构设计、RTL 实现、仿真验证、综合分析与性能优化。
